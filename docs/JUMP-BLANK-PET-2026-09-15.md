# 小精灵空白实验室：从零学机制

基线：origin/main `766f1e6af45b40adb92dfce6e143d8a8c3ad8f5e`。本次 `git fetch origin` 失败（远端返回 `Repository not found`），因此以本地已有的 `origin/main` 为基线，没有更新的远端提交可比对。

## 行为

- `/jump` 新增「空白实验室」区。进入后小精灵只有三个无名通道 a/b/c：**不知道**哪个通道会跳、重力多大、什么算过关、金币和门有什么用。旧的示范课区域（真实模型决策、示范上下文、备题）保持不变。
- 世界布局固定（900 宽、中间 64 像素坑、高台、钥匙、回头开关、锁门），每个世界隐藏抽取五件事：通道到「左/右/跳」的排列、速度、重力、跳跃初速、短跳截断。区间写在 `public/jump-lab.mjs` 的 `RANGES`：速度 2.8–3.8、重力 .45–.65、跳跃 −13.5–−10.5、短跳截断 −6.5–−2.5。任何一次抽取都必须保证这一关可解，测试对区间端点与中间抽样跑完整物理搜索。
- 模型能看到：关卡几何、精灵状态、progress、机制手册、上一段结果、你的备注。**看不到**：通道含义、物理参数、世界种子、目标顺序。种子也不发，因为它可以推出全部隐藏事实。
- 按钮 ① 先验探针：一次实验都不做，先让模型猜三个通道的作用与把握，得到「先验基线」，再和真相对照。
- 按钮 ② 免费实验台：本地物理跑 9 次实验（每个通道短按 6 帧、长按 60 帧，再加三组两两组合），约 650 帧，**不花模型调用**。这一条是成本控制的关键：观察由引擎免费产出，模型只负责归纳。
- 按钮 ③ 归纳：把实验表交给模型写成条目，**状态由服务端按证据计数决定**——1 条支持记「观察」，3 条以上不同实验支持才记「确认」，模型自报的状态会被改写并附上原因，表里不存在的实验 id 会被丢弃。提示词要求模型只能依据实验表、不得引用外部游戏常识。
- 按钮 ④ 让它自己试：精灵只带机制手册行动，输出 a/b/c 通道与帧数，并先给出预测（`dy`、`grounded`、`dead`）。引擎真实执行后给预测打分，面板累计显示命中率。只有「确认」条目可以照着做，其余只能用来提出试探。
- 你的示范：在实验室里点「回去示范」录下的操作会被记成一次 `origin: human` 的带标签实验，与引擎实验并列进证据表。注意：实验台本身已能提供同样的信息，所以你的示范的价值是**更快、更少掉坑**，不是唯一的信息来源。
- 按钮 ⑤ 换世界：上一世界「确认」过的条目会变成「猜想 + 空证据」带到新世界，也就是待复核；每个世界的实验次数、确认条数、预测命中率记入曲线。世界种子、手册与实验记录只保存在当前浏览器。
- 按钮 ⑥ 揭晓真相：显示该世界的通道映射与真实参数，便于人对照手册。另有「清空机制手册」按钮。

## 完整性边界

- 状态升级由服务端计数，不由模型自报；证据 id 必须真实存在于本次实验表。这是防止「自称学会了」的机制。
- 提示词里「不得引用外部常识」只是提示词层面的约束。真正让「学会了」可证伪的是**隐藏参数 + 预测打分**：参数不告诉它，先验就不足以替代观察，预测命中率可以被引擎独立核对。
- 引擎模拟、`verifyLevel` 搜索与关卡生成器仍使用参考物理 `PHYSICS`；隐藏参数只作用于实验室世界，且通过 `step(..., physics)` 与 `verifyLevel(..., { physics })` 显式传入，不改变既有内置关与生成关的行为。
- 未实现：自动反驳跨世界的旧结论；难度评级；布局随世界变化（目前只有隐藏参数与通道排列变化）。

- 自动化：181 项 Node 测试通过（本次新增 14 项：世界抽样与参数区间、通道不透明、免费实验台、不泄漏隐藏事实、先验打分、证据计数升降级、无效动作与越界参数拒绝、页面元素与资产存在、演示转实验、换世界携带与曲线、预测打分）；40 项 Cloud 测试通过；`npm run check` 检查 150 个文件 0 失败；`npm run build` 通过并已把 `public/jump-lab.mjs` 复制进 `dist/client`。
- 真实 DeepSeek 检查（2026-09-15，本地 Node，`AI_MODE=model`，`deepseek-v4-pro`，世界种子 4477）：先验猜测 **1/3** 命中（猜 a=跳正确，b/c 左右猜反，把握 0.3–0.4）；跑完 9 次免费实验后归纳用 8.1 秒，得出 3 条正确结论并全部达到「确认」（a 跳、b 左、c 右）与 3 条组合观察；随后带手册行动，输出「按住 c 60 帧」，预测 **3/3** 命中——引擎回放位移 +175.8 像素、未跌落，与其预测的 `dy=level, grounded=true, dead=false` 一致。
- 第二个世界（种子 90210，映射 a=左、b=右、c=跳，与第一个世界完全不同）：8.9 秒归纳出与真相一致的结论，其中 2 条达到「确认」；模型还从「落回 y=336」推断出踩到了平台，说明它在用实验数据推结构而不是背常识。
- 已知限制（真实模型观察到）：换世界后，上一条世界的旧结论会以「猜想 / 证据 0」留在手册里，模型**没有**主动把它们标为「已推翻」。这不影响行动正确性（只有「确认」条目可用于规划，旧条目是惰性的），但手册会积累过期条目。下一步要么加强提示词，要么在服务端定义结构化结论后做确定性反驳。
- 未做：真实浏览器实玩、整关通关、线上发布。`test/life.test.mjs` 在本次环境中偶发失败（在**未改动**的 main 检出上单独运行 3 次即出现 2 次失败），与本改动无关。
