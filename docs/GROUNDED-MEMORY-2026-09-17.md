# 锚定记忆：治"越学越笨"（2026-09-17）

## 诊断（data/client-log.jsonl，17:12–17:15 第 2 关）

宠物一度到达 x=765（钥匙✓机关✓门开✓，离终点只差 95px），随后连续 8+ 次摔死。链条：

1. 复盘学出正确规则"应从 x≈432 起跳，按住跳 45–60 帧"；
2. 但 tryNext 从**宠物当前位置**（复活点 x=48）执行，"向右 10 帧→跳 45 帧"实际在 x≈80 起跳 → 摔死；
3. 下一次复盘把这次失败归因为"在 x≈432 起跳 45 帧也会死"——**假规则**；
4. 假规则进知识库后被后续决策当"确认知识"引用 → 更错的动作 → 更多假证据，自我强化的变笨循环。

根因是**位置锚定缺失**：尝试卡片只记段起点→段终点，起跳点和摔落点靠模型从动作梗概**猜**；引擎实验锚在段起点（x=48）而不是真实起跳点，测出的"物理事实"本身就是错的。

文献对应：[Reflexion](https://www.alphaxiv.org/abs/2303.11366) 的自生成经验可被错误引用（[IJCAI 2025 综述](https://www.ijcai.org/proceedings/2025/1175.pdf)：模型对环境动态理解不足时产出貌似合理的错误反馈）；[Voyager](https://arxiv.org/abs/2305.16291) 的标准解法是经验入库前经环境验证、条目带可执行锚点；[幻觉技能推荐研究](https://arxiv.org/html/2607.12340v1) 证明未验证的自产记忆必须过滤。

## 改动：记忆装上锚点

1. **客户端逐帧采集锚点**（public/jump.mjs）：`takeOff`（离地前最后一个落地点=真实起跳点）、`fellAt`（摔落位置 x），随情景卡进决策与复盘上下文。引擎实测，零模型成本，模型不用再猜。
2. **引擎实验从真实起跳点出发**（server/jump-model.mjs）：`holdExperiment` 的锚点从"段起点"改为 `takeOff ?? from`，实验数字才是卡住位置的真实物理。
3. **复盘提示词防编造**：位置只允许引用卡片里的 takeOff/fellAt 精确坐标或引擎实验数字，严禁从动作梗概推算；描述失败先核对起跳点。tryNext 明确"从精灵当前位置开始执行，关键动作在别处必须先助跑过去"——堵住"规则说从 432 跳、实际从 80 跳"的执行错位。
4. 决策提示词同步解释 takeOff/fellAt 字段含义。

## 验证

- 新增测试：引擎实验锚在 takeOff（x=400）而非段起点（x=48）；情景卡带 takeOff/fellAt。
- jump 相关 68 项测试全过。

## 限制

- 已有知识库里的旧假规则不会自动清洗——但下一次复盘的证据对照（真实锚点 + 真实实验）可以把它标成「已推翻」；想立即见效可在页面点"忘记这一关"。
- 规则仍是自然语言文本（不是 Voyager 式可执行代码）；锚点保证它引用的位置是真的，但不保证它的外推是对的——证据计数降级机制兜底。
