# 无思考逐步推箱：决策反馈改进

保持 DeepSeek Pro 的 `thinking: disabled` / `reasoning_effort: none`。仅调整逐次推箱模式的观察与撤销工具，不调用多箱求解器，不给模型通关答案，不自动替模型选择下一推。

- 记录最近八次完整推箱决策，包括箱子前后位置、目标变化、回访情况；走路不再冲掉这些记录。
- 按箱子布局和玩家可达区域识别相同决策局面；展示每个选择已试次数和是否回到旧局面。
- 撤销完整的上一推及其接近路线，仍逐格执行引擎的 Z 操作，计时不停、步数不返还。
- 对忽略其他箱子的单箱几何可达性作检查，提示非角落死格，以及两箱无法分配到不同目标的推动。无死锁提示不代表关卡一定可解。
- 列出仍未完成的目标及每个箱子兼容的目标，避免追逐已被另一个无法离开的箱子占用的目标。

## 真实模型固定题对比

预先选定既有固定题 L01、L03，每版本每题一次。沿用 180 秒、60 决策回合、每格 220 ms。保留失败和退步，不用补跑替换；第二版是在这两题上调试得到的，结果不是独立泛化测试。

| 版本 | L01 | L03 |
| --- | --- | --- |
| 修改前 | 通关，61 步，23 回合，37.5 秒 | 失败，255 步，60 回合，118.3 秒 |
| 第一版反馈 | 通关，74 步，28 回合，70.3 秒 | 通关，58 步，11 回合，25.6 秒 |
| 最终版（补目标分配） | 通关，62 步，16 回合，28.9 秒 | 通关，70 步，13 回合，31.1 秒 |

这说明这批样本的长时间循环得到缓解，不能宣称稳定通关率或最短路线。L01 最终步数仍略多于修改前，最终 L03 也比第一版绕路。后续应以未参与调试的题集验证。

脱敏记录在 `.artifacts/push-feedback-comparison/{baseline,candidate,candidate-v2}.json`，包含棋盘、模型选择、操作串及时间，不含密钥或玩家聊天。重放操作确认胜负；62 项本地回归测试通过。
