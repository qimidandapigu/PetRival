# PetRival MVP implementation claim

## Scope and invariants (recorded before implementation)

- Independent game and repository, not a mod or Harness plugin. Touch only this new repository.
- Challenge another pet, not a room or an anonymous level. Each pet keeps a pre-generated, verified ready level.
- Opening a challenge snapshots both ready versions and never awaits a model/generation request. Replenishment runs in the background; old ready levels remain available until replacement succeeds.
- Humans and pets both play. Self-level practice is available without ranked points; ranked human and pet runs attack the opponent's level independently.
- Human failure is a valid result, not a publication gate. Clear +100, failure -20; equal team scores compare ranked completion time. Failed runs use the full time limit, not early-exit time, for the tie-break.
- Server replays moves and owns time, identity, immutable versions and score settlement. A solver proof must never be handed to the competing pet.
- Asynchronous defense is opt-in on pet creation. Human absence does not fabricate a loss: unstarted, abandoned matches expire void.
- Ranked matches require two real owners. Clearly labelled training pets can be challenged without another person, but do not manufacture human results or change the ranked ladder.
- Preserve active games across reload/restart. Scores settle once. Generation failure must not discard the last verified level.
- No payments, subscriptions, voice, growth tree, formal production hosting, Harness installation changes, or cross-task dispatch.

## Entrypoints and verification

- Browser: adopt pet, ready-level practice, rival list, instant challenge, manual puzzle controls, agent replay, result and pet leaderboard.
- Server: guest ownership, durable state, bounded background jobs, generation, actual action replay, challenge clocks, ranking and restart recovery.
- Provider: explicit algorithm mode without credentials; optional server-side compatible chat endpoint for model generation/playing. Never claim live model acceptance without a real call.
- Tests: deterministic mechanics/generation; real HTTP two-owner lifecycle; forged results/ownership; score/time/failure; cache/snapshot replacement; idempotency; timeout/restart; provider mock only at the external HTTP boundary.
- This is a new repository, so there is no previous implementation to reproduce. New behavioral tests are not evidence of repairing an old defect. Any defects discovered during work will receive a failing behavioral test before correction.
- Verify a real browser interaction in addition to tests. Report source, tests, browser, model, GitHub branch/PR and hosting separately.
