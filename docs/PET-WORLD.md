# 晴风小院：生活场景与对话

首页以宠物生活的小院为主体。桌面左边是持续活动的像素田园，右边是聊天；窄屏改为上下排列。当前本地预览为 http://127.0.0.1:4390/#pet-world 。

## 可以体验的内容

- 小屋、菜园、野餐角、池塘和村间小路；使用宠物自己的像素外观，有行走、浇水、进食和休息动画，以及昼夜变化。
- 宠物按日常安排自主散步、照料菜地、吃东西和休息；没有生活控制按钮，点击房屋或菜地也不会派发指令。点击宠物只聚焦聊天，游戏牌只导航至游戏小屋。
- 活力、饱腹和心情随时间与实际完成的活动变化；浇水后蔬菜逐渐生长，成熟后再次照料可收获。
- 聊天读取当前活动、地点、状态和近期生活事件，也可以影响接下来的行动。例如说“回屋休息一会儿吧”，宠物可以回应并走回小屋；普通问候、状态询问和否定不是生活指令。
- “游戏小屋”保留推箱子入口，原有等级、经验与技能里程碑仍然可查看。具体成长规则见 [COMPANION.md](COMPANION.md)。

## 实现边界

这是可互动的田园生活原型，尚未实现完整农场经营、背包、NPC 社交或开放世界。日常安排目前由生活模拟规则驱动；模型根据对话和当前状态决定是否提出散步、照料、进食或休息，服务端验证后执行。本地算法模式只支持有限的明确请求，并标明“本地规则回复”。聊天不能改等级或解锁技能；技能库仍记录真实通关后的里程碑，并非可执行技能代码。

生活状态由服务端时钟驱动并写入 JSON 存档，离线补算最多三分钟。聊天返回的结构化动作必须通过白名单验证，有效回复与动作一起保存；同一请求标识只执行一次，重试不能重新启动已执行的动作。动作完成后才结算效果，回复不能冒充完成事件。旧存档首次启用生活系统时从当下初始化。客户端按状态版本接收更新，避免迟到的聊天或轮询响应覆盖新动作；行走途中切换活动会从当前位置继续。

- 全套 77 项测试通过；修复迟到轮询可能拨回动画时钟的边界后，7 项界面并发测试再次通过。语法与基础密钥模式扫描通过。
- 更新并重启 4390 本地模型预览。浏览器实际发送“天快黑了，回小屋休息一会儿吧。”，DeepSeek 回复“好呀，我这就回小屋休息。”；画面显示宠物走到小屋，存档 `activity=rest`、`source=conversation`，20 秒后保存休息完成事件。
- 实际发送“不要去浇水，跟我聊聊就好。”，回复“好呀，你想聊点什么呀？”；自主生活继续，未新增聊天来源的浇水活动。否定语句不会被当作对应的正向指令；当前版本不支持停止或长期禁止自主日常。
- 宽屏与 390 px 手机宽度检查通过，生活动作按钮数量为 0；手机可用内容宽度与页面宽度均为 375 px，无横向溢出。
