# 拳台攻防第一轮调整

基线：fetch 后 origin/main 86e2165f79efb526c0ab17e6da08c3587d2b3a4d；独立 codex/boxing-balance 工作树。功能交付提交 `0cbda7e` 已整合入 main；整合复跑 189 项测试全部通过，发布状态以统一发布任务的记录为准。

## 问题与行为
旧版重拳既有更高伤害又有更长距离，防守只有减伤收益。新规则增加“防重拳后反击 → 抱摔破防 → 轻拳打断抱摔/后退骗空”的选择。

- 基础血量 30；真人对手仍 150 血、5 倍伤害，没有静默修改用户要求的挑战倍率。
- 轻拳 3 / 起手100ms / 收招250ms / 距离114；重拳 6 / 起手350ms / 收招700ms / 距离125；抱摔 4 / 起手300ms / 收招650ms / 距离102；有效判定50ms。
- 普通拳防住零伤害，防轻拳硬直100ms、防重拳150ms；重拳剩余收招足以让防守者打轻拳反击。
- 抱摔忽略防御，但并非无敌，可被更快的轻拳打断，或走出距离使其落空。
- 收招期间无法取消为移动、防御或其他攻击；惩罚收招加2基础伤害，再乘进攻方倍率。
- 按住仍可连续行动，松开恢复站立，抱摔和拳击均保留短按输入缓冲。I 和触屏按钮可抱摔。
- 最近16条可见出招/结果保存在本局状态，模型仅接收最近10条及当前收招信息。原技能快照、100 token限制保留，新增合法动作 throw。
- 算法陪练读取可见动作，能防重拳、对防守抱摔和攻击收招。模型模式仍由模型/用户既有技能执行，没有暗中替换为算法。云端/Node共享说明，仍无思考，1至3个短动作。
- 画面和棋盘下方显示打空、挡住重拳、抱摔、反击信息。
