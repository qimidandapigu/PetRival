# 学习回路修复：通关转示范、规则收敛、战略脱困（2026-09-17）

日志诊断（data/client-log.jsonl，第 3–6 关期间）暴露的三个结构性问题，本次修复：

## 1. 通关自动转示范（最强信号此前被丢弃）

问题：第 3/4/5/6 关都是人手动通关的，但示范数为 0——示范只在专门"教学模式"录制，
正常通关的完整成功操作被直接丢弃，宠物进新关永远零教材。

修复（`public/jump.mjs`）：被动全程记录器 `autoRec` 记录人的每一条命（不占教学模式、
不限制段数）；人通关时 `saveAutoDemo()` 把整段操作重切为合法示范块（每动作 ≤90 帧、
每块 ≤12 动作 / ≤240 帧），并用 `replayActions` 逐块回放得到**真实的 from/to 状态**，
存入示范库（samples）。之后的决策（freshSamples）和复盘自动可见。配合关不自动生成。
init/goToStage/restartRound/resetLevel/人摔死复活 都会重置记录器。

## 2. 规则收敛（同一知识不再被反复"重新发现"）

日志证据：「金币必须身体碰到」被三次复盘写成三条新规则（证据 1/1/1）；跳跃位移表有
三个互相矛盾的【通用】版本，其中两个来自被门/地形挡住的实验锚点（全 0px 假物理）。

修复（`server/jump-model.mjs`）：

- **id 复用**：复盘提示词要求更新已有规则必须复用其 id——`reduceNotebook` 本来就按
  id 合并证据，复用后证据才能累积升级，手册收敛；
- **scope 校验**：scope=通用 的规则若含绝对坐标（x≈/x=/起跳 x/落点 x），服务端强制
  降为「这一关」——通用物理只能是相对量（"按住 1 帧≈58px"）；
- **实验遮挡标注**：`holdExperiment` 对"按住 ≥10 帧却几乎没位移且没摔死"的探测机械
  标注「被地形或关着的门挡住，只适用于此位置，不是通用物理」，堵住假通用规则的源头。

## 3. 战略脱困（知道该后撤，真的会后撤）

日志证据：x=806/x=968 处连续 6–7 次复盘都正确得出"要向左走再跳"，但 frontier 只认
max x、tryNext 限局部变体，决策继续向右硬冲。

修复：

- `stallStreak`（`public/jump-lab.mjs`）：尝试事件里含 捡到金币/取得钥匙/踩机关/压力板
  视为进展——回头收目标物不再被误判为"卡死"；
- 复盘提示词（`server/jump-model.mjs`）：连续卡死 ≥4 次时明确要求 tryNext **战略性
  改变**——向左后撤到空旷/低位区域，或转向未完成的目标物，不要向右硬冲同一位置。

## 顺带发现（未改）

日志里"x=968 头顶空间不足"实为**关着的门**挡住（门只挡横向、高门挡跳），模型把门
误读为天花板。归因层（ATTRIBUTION-CALIBRATION）的门事件 + 本次实验遮挡标注都
已覆盖这个误读路径。
