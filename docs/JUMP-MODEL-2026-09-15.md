# 小精灵跳跳课：真实模型与复杂关卡

基线：origin/main `6eea758806330e693b8a8c7ef8d8f65a144d6c10`。根目录为实现；发布状态单独记录。

## 行为

- `/jump` 与 `/jump.html`。精灵的动作来自服务端 `PetBrain.json` 的真实模型输出，包含方向、跳跃键与有限帧数；当前页面不再使用旧 `PetController`。未配置模型时拒绝调用，不提供算法代打。
- 每段动作后反馈位置、物品与跌落结果。模型等待时仅精灵的物理时间暂停，玩家可继续移动。请求中断、无效动作、重开与换关均不能让过期动作误执行。每轮最多16次调用，玩家可主动继续。
- 点击“回去示范”，从精灵当前状态录制最多240帧、12段真实操作。成功存活与跌落均标注结果，最近4次完整示范作为模型上下文。不是微调权重，不保证一次学会，也不等同学到了完整人格。
- 示范只存当前浏览器，按已有宠物区分，最多8次。旧v1笔记保留但不自动转成v2示范。无跨设备学习同步、无积分结算；模型调用有实际Token用量。
- 人类不能收集金币、钥匙、开启机关或完成精灵的胜利条件。只有精灵收齐金币、拿钥匙、踩开关、抵达终点才完成。

## 关卡生成与验证

- 初始关为明确标注的内置验证关，不冒充模型生成。加入高台、钥匙、回头开关、锁门与金币支路。
- 模型直接生成宽800–1600、最多14平台、1–5金币的原创几何；不是只随机换颜色。物理模块统一执行移动、短跳/长跳、单向平台、门与物品。
- 验证器有界搜索最多9000节点，找到路线后用相同物理完整回放。找不到只能判为未验证，不能证明无解。最多一次模型修复；仍不通过则保留原关。复杂度来自路线结构，尚无难度评级、移动平台、敌人或关卡能力升级。
- 验证通关动作不包含在API响应，也不送给闯关模型。生成与决策分别限流，后台备好的关只在点击进入后切换。

## Node / Sites

同用 `server/jump-model.mjs` 与 `public/jump-world.mjs`。Node沿用服务端会话；Sites沿用手机号、ChatGPT身份或访客会话。Sites使用短事务获取每用户请求租约，模型请求在D1事务外，完成后释放；长请求有心跳。没有新增数据库结构或更改身份、付费、积分逻辑。

备题显式关闭长思考，避免旧preparation通道默认高思考挤占JSON输出预算。单次备题最长120秒、最多两次；决策最长90秒，客户端超时留余量。错误不会提交伪造通关。
