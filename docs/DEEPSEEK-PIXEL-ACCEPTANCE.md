## 自动检查与回归证据

最终隔离副本运行 `npm test`：**40 / 40 通过**；`npm run check` 语法和基本密钥模式扫描无失败，`git diff --check` 通过。测试涵盖真实 HTTP 双主人身份、固定关卡版本、通关回放校验、超时、榜单只结算一次、模型故障分类、像素文件校验和落盘。

新增核心验证：

- 真正挂起模型规划 HTTP 请求时，真人仍可开始；第一段动作执行后、第二次规划尚未返回时，自己的 AI 步骤已经可见，对方步骤仍保密。原 `fde101b` 在“已执行前缀应可见”断言上失败，候选通过。
- 后台生成请求挂起时，两只参赛 AI 的规划请求都能到达供应商；备题和闯关分别限流。
- 实际动作每步执行 220ms，思考与执行的时间只计算一次；整场最多 180 秒。取消服务会中止正在调用和排队的请求。
- AI 正在运行时重启服务：本场作废、保留已经执行的操作，不重新获得完整时限，也不扣排名分。
- 模型给出非法动作或 JSON null 算挑战失败；基础设施故障作废。
- 同一真人提交完成后，先前发出的迟到轮询不能恢复“进行中”；旧局响应不能覆盖新局；试玩获取固定关卡前不接受会被清空的操作。前两类旧行为已用同一生产入口测试复现失败。
- 外观只允许主人修改，持久保存；伪造积分、身份字段或可执行颜色被拒绝；导出不含账号、关卡、积分或凭据。
- 对手回放在 AI 棋盘播放，保留对手形象、名字及原模型标识，不挪到真人棋盘。

这些测试中的外部故障由本地 HTTP 服务模拟，内部队列、游戏执行器、鉴权和保存走真实实现；不等同于真实供应商所有故障已经验证。
