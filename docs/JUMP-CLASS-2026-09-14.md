# 小精灵跳跳课：横版示范学习试玩

> 本文记录 v16 历史实现；当前模型版见 [2026-09-15 更新](JUMP-MODEL-2026-09-15.md)。

入口为游戏小屋里的「小精灵跳跳课」，也可直接打开 `/jump.html`。这是原创横版平台小游戏，采用独立页面保留操作空间；返回小院可继续原有推箱子、打拳和对话。

## 当前玩法

- 玩家与小精灵同时位于一关，各自移动，不互相碰撞。左右或 A/D 移动，空格或 W/上方向跳跃，松开跳跃键会缩短跳跃。手机提供多点触控方向与跳跃按钮。
- 玩家负责示范，不能收集金币、触发机关或替小精灵完成终点。只有小精灵接触物件才改变通关进度。
- 小精灵初始只会向右走，不知道怎么跳；跌落后等待示范，玩家仍可继续操作。
- 玩家在小溪前起跳并成功跨坑落地后记录示范，立即供小精灵尝试。卡住时「回到它身边示范」将玩家放回小精灵最近的安全落脚点；成功示范后自动重试，也可手动重试。
- 三个短关依次提供窄溪、同宽异地双溪、不同宽度双溪。按形状匹配，不用新关卡的固定坐标回放。每关由小精灵收齐三枚金币、踩机关、到达终点才结束。

## 学习的实际边界

当前是基于成功示范记忆的模仿控制，不是神经网络训练或大模型逐帧操控。`DemonstrationRecorder` 记录玩家真实执行的起跳距离、溪宽和逐帧方向/跳跃键；仅成功跨坑才入库。`PetController` 按相近溪宽选择实例，在相对起跳位置执行该片段。基础向右行走内置，跳跃片段来自示范，没有隐藏的通关求解器、自动专家或预装跳跃笔记。

它暂时只学习跳跃技巧，不能据此宣称已经模仿完整玩家个性。按键抖动、不同落点和不恰当示范可能造成失败；尚无复杂地形、敌人、路线选择或训练泛化的玩家规模评估。每个行动由本地确定性物理执行。

## 身份和保存

有当前宠物时读取其外观、显示名和 ID；没有宠物也可用试玩小精灵立即练习。学习笔记用 `localStorage` 按宠物 ID 区分，游客用独立 guest 槽。最多 80 条，载入时校验类型、长度、数值边界。仅当前浏览器保存；不上传 D1、不跨设备、不影响账号经验或排行榜。失败重来保留笔记，显式清空只处理当前笔记。关卡位置及本局收集进度不跨刷新保存。

Node 与 Sites 运行同一份前端物理、记录器和控制器；Node 增加四条静态路由，Sites 使用现有静态资源服务。无数据库迁移、模型调用、环境配置变更。

## 验证

- 确定性动作测试：未训练失败 → 成功示范 → 同关通关 → 两处新位置的同宽溪通关；更宽溪失败后补充示范可通关。
- 物件权限测试：玩家触碰金币、机关和终点不改变进度；小精灵可完成。
- 失败跳跃和平地跳不记入；笔记序列化/载入后可继续使用，非法笔记丢弃。
- 自动化页面夹具通过键盘事件操作实际页面模块，验证示范写入对应宠物的本机笔记、等待中的小精灵恢复并完成、换关保留笔记。该验证不是浏览器手动完整通关。
- 本地浏览器已实际打开并检查画面、暂停和返回示范入口。浏览器自动控制不支持持续按住组合键，完整教学通关由上述自动化夹具验证，留待用户实玩。
