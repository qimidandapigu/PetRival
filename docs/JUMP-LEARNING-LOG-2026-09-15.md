# 小精灵学习日志与「它现在会什么」

基线：origin/main `ca7bbcf`（世界模型即代码）。`git fetch origin` 仍失败（远端 `Repository not found`），以本地 `origin/main` 为基线。

## 为什么要加

玩家反馈：**"目前这样我真的看不出来"**。之前页面只有"结果"——手册条目、代码面板、成绩条——没有"过程"：哪一步做了什么、哪一步花了模型调用、这一轮比上一轮好了多少、它到底已经会什么、还有什么不知道。这一步只补可见性，不改变任何学习机制。

## 行为

- 新增 **学习日志**：每一步追加一行，带时间戳与分类标签（世界 / 先验 / 实验台 / 你的示范 / 归纳 / 学到 / 世界模型 / 规划 / 行动 / 预测 / 揭晓 / 失败），最新的在最上面，最多 160 行，随实验室状态一起存在当前浏览器。记录内容包括：
  - 换世界：第几个世界、种子、带过来几条待复核；
  - 先验猜测：每个通道猜成什么、把握多少、命中几个；
  - 实验台：跑了几次实验、记了多少帧、**花了 0 次模型调用**；
  - 你的示范：几帧、起点终点、存活还是跌落、**0 次模型调用**；
  - 归纳：第几次模型调用、读了几条实验、新增/确认/被服务端按证据改写各几条、耗时几秒，并为最后 4 条手册条目单独写「学到」行；
  - 世界模型：**每一轮修复单独一行**（第 N 轮逐帧比对多少帧、对上多少帧、最差偏差几倍容差；跑不起来的那一轮写失败原因），再加上"通过/未通过"结论和它自己从表里读出的数字；
  - 规划与真跑：模型内搜出几段路线、预测落点，以及真引擎执行后的实际落点与是否成立；
  - 行动：第几次决策、几段按键、目标是什么、参考了几条手册、有没有先下预测；
  - 预测打分：命中几个、错在哪个字段、累计命中率；
  - 揭晓：真相的通道映射与四个物理参数。
- 新增 **「它现在会什么」面板**：用大白话把当前状态摊开——
  - 运动的掌握程度（世界模型是否 0 误差、覆盖多少帧）；
  - 每个通道已知什么（列出「确认」条目里提到该通道的结论）或**还不知道**；
  - 揭晓之后逐通道标注 **✓ 和真相一致 / ✗ 和真相不符 / — 没有对应结论**（比对方式是关键词匹配：结论里是否出现"左/右/跳"，属于提示性对照，不是语义判定）；
  - 手册统计：确认 / 待验证 / 猜想 / 已推翻各几条；
  - 模型调用次数、引擎实验次数、你的示范次数、它自己执行的次数、预测命中率、历史世界曲线。
- 服务端 `/api/jump/lab/model` 新增 `rounds` 字段：每一轮的 `{round, matched, frames, error, worst, problem}`。日志里的"每一轮"就来自它——这是玩家唯一能看见"确实在变好"的地方。

## 修正：默认玩法里看不到日志（2026-09-15 补记）

玩家反馈"我要的日志呢，为什么没有日志"。原因是我自己写的渲染守卫：`updateLab()` 开头是 `if (!lab.world) { … $('#lab-log').textContent = '还没有记录。'; return; }`——**只要还没进入空白实验室**（也就是默认的示范课玩法），每次刷新界面都会把日志栏覆盖成"还没有记录。"，即使里面已经记了跌落、重开和示范。

修了三处，并按"默认玩法也要有日志"补齐事件：

- 日志渲染抽成 `renderLog()`，放在 `lab.world` 守卫**之前**无条件执行；「它现在会什么」在没进实验室时给出解释性文案（说明日志已经在记，进实验室后才会显示学到什么）。
- `logEvent()` 内部直接 `saveLab()`：示范、跌落、复活、重开、每次决策都当场落盘，不再依赖别的路径顺手保存。
- 示范课（经典模式）补齐三类事件：开始闯关、每次决策（含参考了几次示范与耗时）、每次示范录制与结果；空日志的提示文案改为列出"将来会出现什么"。
- 日志分类新增「跌落」「通关」两个标签。

- 该次检查同时验证了容错行为：第 2 轮遇到提供方抖动时，请求没有整体失败，而是保留第 1 轮结果并把失败原因写进 `rounds` 与日志——玩家看到的是"这一轮没跑起来"，而不是空白。

## 限制

- 日志是本地浏览器的记录，不跨设备同步；清空手册会一并清空日志。
- 「✓ 和真相一致」是关键词匹配（结论里是否出现"左/右/跳"），措辞奇怪的正确结论可能被判为"没有对应结论"，不会误判为一致。
- 日志只记录实验室内的动作，不记录经典示范课的模型调用。
