# 游戏选择、宠物对话与成长

本轮在现有 PetRival 本地 Node 服务中增加了宠物首页。保留推箱子双棋盘、备题、对战和外观编辑。

## 使用

1. 领养宠物后，在首页选择推箱子；当前游戏目录仅提供推箱子。
2. 点击“进入推箱子”开始人宠同玩，也可以向下选择对手。
3. 在“和宠物聊聊”输入消息，Enter 发送，Shift + Enter 换行；中文输入法确认候选词不会误发送。
4. 技能库显示等级、经验和解锁条件。点击技能卡查看成长记录。

## 数据与规则

- 宠物从 Lv.1 开始，100 XP 升一级。服务端重放验证宠物成功完成一张此前未通过的地图后奖励 40 XP。相同地图哈希只奖励一次。
- 首次、累计 3 张、累计 5 张不同关卡通关分别解锁“初识路线”“路线探索”“推箱伙伴”。**当前技能库记录通关里程碑，尚不包含可以执行的学习代码或能力加成。**
- 聊天、玩家通关和备题的可解性证明不会增加宠物经验；宠物成功完成练习也可成长，排行榜计分规则保持独立。
- 游戏选择、经验、技能和最近 60 条聊天持久化在服务端 JSON 存档。聊天只允许对应宠物主人访问，不出现在对手和排行榜数据中。模型每次只接收最近 20 条对话以及允许公开给模型的宠物事实。
- 模型模式使用已有服务端配置，聊天限时 45 秒、最多 1024 输出 tokens。历史助手回复按 JSON 格式发送，兼容 DeepSeek 的 JSON 输出模式。本地算法模式显示“本地规则回复”。模型失败保留消息并允许重试，不生成假回复。
- 重复发送使用请求 ID 去重。刷新列表不会抹掉草稿；重试旧消息不会删除新草稿，回复到达也不会抢走其他输入框的焦点。

## 本轮验证

- `node --test test/*.test.mjs`：56 项通过，包含 HTTP 身份边界、聊天去重与失败恢复、持久化、真实执行后成长、中文输入和草稿保留。
- `node scripts/check.mjs`：语法与基础密钥模式扫描通过。
- 浏览器实际操作：领养、规则聊天、游戏入口、左右棋盘独立操作、宠物 17 步通关后获得 40 XP、解锁第一项技能、刷新后聊天与成长保留。
- 390 px 窄屏检查：页面内容宽度与可用视口宽度相同，无横向溢出。
- 真实 DeepSeek 请求已返回与测试存档一致的等级、40/100 XP 与“初识路线”说明。使用本轮生成的测试消息，无用户私人聊天。
