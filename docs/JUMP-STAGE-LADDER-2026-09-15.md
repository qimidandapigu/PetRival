# 小精灵跳跳课：关卡阶梯、右栏「它现在会什么」、日志排版

基线：origin/main `434c85f`（日志可见性修正）。`git fetch origin` 仍失败（远端 `Repository not found`），以本地 `origin/main` 为基线。

## 为什么

玩家要求三件事：**日志排版优化**、**"模型学到啥了"要能在右边看到**、**一关一关来（先走路，再跳，再吃金币，再吃钥匙……）**，目的是"能感到宠物越来越聪明，而不是一上来就比较难过不了、有挫败感"。

## 行为

### 1. 关卡阶梯（六关，每关一个技能）

| 关 | 名字 | 新技能 | 关键设计 |
|---|---|---|---|
| 1 | 先学会走 | 一直往右走 | 全平地。金币、钥匙、机关、门、终点排成一条直线，**只会走路就能通关** |
| 2 | 学会跳 | 跨过小溪 | 一个 80 像素的坑；走出去会掉下去，跳一下才过 |
| 3 | 学会拿金币 | 跳上矮台收金币 | 一枚金币在矮台上，必须跳上去 |
| 4 | 学会取钥匙开门 | 上高台取钥匙 | 钥匙在两段台阶上；开关就在附近，还不用回头 |
| 5 | 学会回头开机关 | 拿到钥匙往回走 | 钥匙在右边高台、开关在最左边，必须回头 |
| 6 | 高台上的钥匙 | 把全部动作连起来 | 就是原来的内置关（高台 + 回头 + 跨溪 + 金币支路） |

- 关卡条在画面正上方，六个胶囊按钮：通过的打 ✓，当前的加深，未解锁的显示 🔒 并写明"先过第 N 关"。
- **解锁规则：任一方通关就解锁下一关**（小精灵过算过，你自己过也算过）——这样不会因为模型一时过不去而把你卡住。通关时会写进日志，结束面板的按钮变成「进入第 N 关：xxx →」。
- 进度存在当前浏览器（`petrival.jump.stage.v1`，按宠物区分），刷新和重开都还在。已通过的关可以随时回去重玩。
- 六关**全部通过求解器验证**：`verifyLevel` 找到通关路线并用同一套物理回放确认，测试里逐关断言。

### 2. 右栏「它现在会什么」

页面变成三栏：**左＝学习日志，中＝游戏，右＝它现在会什么**（1200px 以下右栏折到下面一行，900px 以下全部堆叠）。

- 示范课里右栏显示：已经通过几关（哪几关）、当前关要求什么、**小精灵这一关用了多少次模型调用 / 跌了几次 / 它现在想做什么（模型自报的目标）**、你自己这一关的数据、双方通关次数、你的示范次数与最近一次结果、下一关是否已解锁。
- 空白实验室里右栏显示原来那套：世界模型是否通过、通道结论（还不知道哪些）、揭晓后的 ✓/✗ 对照、手册统计。

### 3. 日志排版

- 不再是等宽大段文字：**每行一个元素**，三列网格 = 时间（等宽小字）+ 分类标签（彩色小胶囊）+ 正文（自动换行、左对齐成列）。
- 分类配色区分：世界 / 重开 / 实验台 / 你的示范 / 归纳 / 学到 / 世界模型 / 规划 / 行动 / 预测 / 跌落 / 通关 / 失败。
- 空状态文案改成"将来会出现什么"，不再是一句"还没有记录"。

## 验证记录

- 自动化：203 项 Node 测试（新增 6 项：六关全部可解且能回放、阶梯每次只引入一个技能、第 1 关只靠走路可通、第 2 关走着会掉/跳一下能过、解锁与锁定规则、关卡条与右栏渲染；另更新两处旧断言以适应新关卡与新布局）、40 项 Cloud 测试、`npm run check` 161 文件 0 失败、`npm run build` 通过。
- 关键断言不是"看起来对"：第 1 关的平地被断言为**所有平台 y 都是 400**且"只按右键"能拿到 `won`；第 2 关被断言为"一直走会 `dead`"且"按 40 帧跳跃能落到对岸"；每关都跑一次 `verifyLevel` + `replayActions`。
- 未做：真实浏览器观感确认（三栏在窄屏的折行、日志配色、关卡条换行都只有夹具断言）、线上发布。

## 限制

- 阶梯只作用于**示范课**；空白实验室仍是"一个世界一套隐藏机制"的玩法，没有改成六关。
- 没有难度自适应：摔得多不会自动变简单，只能靠"回去示范"或自己先过一遍解锁下一关。
- 关卡布局固定、不随机；大模型备关（`/api/jump/generate`）仍然走原来的路径，不参与阶梯。
